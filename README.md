# Кластеризация регионов ПФО по социально-экономическим показателям

Алгоритмическое и программное обеспечение на Python для иерархической кластеризации объектов на многомерных социально-экономических показателях. Программа сравнивает центроидный метод и метод Уорда на данных Росстата по 7 отраслям валовой добавленной стоимости 14 субъектов Приволжского федерального округа за 2022 и 2023 годы.

## Файлы проекта

* `main.py` — запуск расчётов из командной строки и сохранение итоговых таблиц.
* `data_loader.py` — чтение листов из `.xlsx`, проверка данных на пропуски и z-стандартизация признаков.
* `cluster_engine.py` — вычисление матрицы евклидовых расстояний, агломерация, проверка монотонности слияний и расчёт метрик (S(K), DB(K), кофенетической корреляции и ARI).
* `visualizer.py` — отрисовка дендрограмм, графиков метрик и схемы взаимодействия модулей (`.png`, 300 dpi).
* `data.xlsx` — исходные матрицы наблюдений (14х7) за 2022–2023 гг. (в постоянных ценах 2021 г., тыс. руб.).
* `requirements.txt` — необходимые библиотеки.

## Установка и запуск

```bash
pip install -r requirements.txt
python main.py
```
Чтобы указать свои пути к файлам и папке с графиками:

```bash
python main.py --input "data.xlsx" --output-xlsx "Результаты_кластеризации.xlsx" --figures-dir "output_figures"
```

## Результаты работы
После запуска в корневой папке создаётся книга  `Результаты_кластеризации.xlsx` (листы Метрики_качества, Устойчивость_ARI, Z_матрица_2022, Z_матрица_2023), а в каталог `output_figures/` сохраняются 4 дендрограммы, сводный график метрик и схема модулей.
